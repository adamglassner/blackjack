# Blackjack — The Gold Room

An Ironite card game: player vs. dealer at a casino table with dark green felt and gold trim. **Play money only** — chips have no cash value, no purchases, no accounts.

Part of the [Ironite Launcher](https://ironite.io) collection. Ships as its own Windows setup and is also bundled in the launcher.

## Features

- Single Deck, Double Deck or 6-Deck Shoe, with a live count of cards left
- Hit, Stand, Double Down and Split (up to four hands)
- Dealer stands on all 17s; Blackjack pays 3:2
- Original card art, music and sound effects, all generated by the game
- Chip balance, stats and settings saved to `%APPDATA%\Ironite\Blackjack`, outside the install folder

Keys: **H** hit, **S** stand, **D** double, **P** split, **M** music, **F11** full screen.

## Layout

| Path | What it is |
| --- | --- |
| `web/` | The game itself (HTML/CSS/JS, fonts, art). `core.js` and `base.css` are the shared Ironite game core. |
| `shell/` | Go wrapper: serves `web/` on 127.0.0.1, opens it in an Edge app window, and keeps the save file in AppData. |
| `build.sh` | Builds `dist/Blackjack/Blackjack.exe` plus its text files. |
| `installer/` | Inno Setup scripts for the standalone `Blackjack-Setup-v<version>.exe`. |
| `icon-1024.png` | Source icon for the exe and installer. |

## Building

Requires Go 1.24+ and bash.

```bash
./build.sh
```

To embed the Windows icon and version info, point `LAUNCHER` at the Ironite Launcher source (`il/ironite-cgc`), which contains the `mkres` tool:

```bash
LAUNCHER=/path/to/il/ironite-cgc ./build.sh
```

The version comes from the top entry in `web/CHANGELOG.md`.

### Installer

The installer scripts expect the launcher's `installer/inno/assets` (wizard images and `.ico`) and the built game under `installer/files/Games/Blackjack/`. Compile with Inno Setup 6.3+:

```
ISCC.exe installer\BlackjackSetup.iss
```
